\problemname{Moderately Angled Triangles}
A \emph{moderately angled} triangle is what we in this problem call a triangle where at least one of the angles is exactly 60 degrees. The moderately angled triangles often feel overlooked compared to the much more well-known right-angled triangles (a so-called lesser-angle complex), despite the fact that the moderately angled ones also have a nice formula for their side lengths:
\begin{equation*}
	c^2 = a^2 + b^2 - ab
\end{equation*}
Write a program that brings some justice to this triangle drama by asking for a number $N$ (between $1$ and $100$) and then outputting how many moderately angled triangles there are whose sides are integers in the range $1$ to $N$.

\section*{Input}
The input is the integer $N$ ($1 \leq N \leq 100$).

\section*{Output}
Output an integer: the number of moderately angled triangles that satisfy the criterion.

\section*{Scoring}
Your solution will be tested on a set of test groups.
To earn points for a group, you must pass all test cases in that group.
